# Security policy

## Reporting a vulnerability

Please report a vulnerability privately, not in a public issue. Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, which plugin it affects, and the steps to reproduce it.

## Supported versions

Fixes go into the latest release of each plugin (handoff, pickup, context-nudge and challenge). Older releases are not patched.

## What to expect

Reports are acknowledged on a best-effort basis. This is a small project with no guaranteed response time.
